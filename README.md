# Portfolio – Vincent Sonneck

Meine Portfolio-Webseite als Frontend Developer. Gebaut mit **Angular 22**, **TypeScript** und **SCSS** nach dem Figma-Design der Developer Akademie.

## Projekt starten

Voraussetzung: Node.js 24.15 oder neuer (LTS). Node 22 geht auch, dann aber mindestens 22.22.3.

```bash
npm install
ng serve
```

Alternativ zu `ng serve` geht auch `npm start`.

Danach ist die Seite unter `http://localhost:4200/` erreichbar.
